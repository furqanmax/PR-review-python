What happens
  1. Read commits in your branch that are not in the base branch.
  2. Rewrite the email on GitHub and create two new branches. Your branches are never changed.
  3. Create the PR (or reuse an existing one).
  4. Review report to Slack when the bot has finished. Follow it under Jobs & progress.
